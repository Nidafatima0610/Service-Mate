# Known Limitations & Scope Boundaries

In accordance with internship specifications, this application adheres to sensible defaults and demo constraints. The following items describe scope boundaries and limitations:

1. **Simulated Availability:** Available dates and time slots are algorithmically generated by the `MockServiceApiClient` to represent realistic booking availability. They do not connect to live commercial scheduling systems (e.g. Google Calendar API or Calendly).
2. **Demo Payment Processing:** The pricing breakdown calculates real base costs, platform fees (5%), and taxes (8%), but transactions are strictly simulated. No real payment gateways (such as Stripe, Apple Pay, or PayPal) were included, preserving application safety.
3. **Local Device Persistence:** Data is persisted in `SharedPreferences` on the client device. It persists reliably across app restarts, but is not synchronized to an external multi-tenant cloud database (e.g. Firebase or Supabase), matching the internship scope.
4. **Geolocation / Live Maps:** Location addresses are handled as structured text strings with default demonstration location in the San Francisco Bay Area. Live GPS tracking and turn-by-turn map navigation are excluded from scope.
